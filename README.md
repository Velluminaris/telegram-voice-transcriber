# TelegramVoiceTranscriber

1) python -m venv .venv
2) .venv\Scripts\activate
3) pip install -r requirements.txt

```
python .\transcribe.py           # обработать все .ogg в папке 'voices'"
python .\transcribe.py N         # обработать последние N файлов в папке 'voices'"
python .\transcribe.py file.ogg  # обработать конкретный файл"
```
